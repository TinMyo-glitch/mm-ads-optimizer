# Myanmar Facebook Ads Optimizer — Vercel Static Version

Login မလိုသော Static website ဖြစ်သည်။ Build လုပ်ရန် ဘာမှ မလိုပါ — `index.html` ဖိုင် တစ်ခုတည်းဖြင့် အလုပ်လုပ်သည်။

## ပါဝင်သော Features
1. 🎯 Precision Audience Builder — Audience ၃ စုံ အလိုအလျောက် ထုတ်ပေးပြီး Copy ကူးနိုင်သည်
2. 🛡️ Policy & Creative Checker — Risk Score + ပြင်နည်း အကြံပြုချက်
3. 💰 Budget & Results Estimator — USD / ကျပ် ခန့်မှန်းချက်
4. 📡 Live Ads (Myanmar) — Meta Ad Library တရားဝင် site သို့ Category အလိုက် Live link ၁၇ ခု + ကိုယ်ပိုင် Keyword ရှာဖွေမှု
5. 📈 Daily Snapshot Tracker — နေ့စဉ် အရေအတွက် မှတ်တမ်း + Trend နှိုင်းယှဉ်မှု (CSV ထုတ်နိုင်)
6. 👀 Competitor Tracker — ပြိုင်ဘက် Page မှတ်တမ်း + Winner အဆင့်သတ်မှတ်ချက် (CSV ထုတ်နိုင်)

## အရေးကြီး မှတ်ချက်များ
- မှတ်တမ်းများ (Snapshot / Competitor) ကို သုံးသူ၏ Browser `localStorage` ထဲတွင်သာ သိမ်းသည်။ စက်/Browser ပြောင်းလျှင် မှတ်တမ်း မပါသွားပါ။ လူအများ ကိုယ်စီ မှတ်တမ်း သီးခြား သိမ်းချင်လျှင် Login + Database ပါသော Full version လိုအပ်သည်။
- Meta က မြန်မာနိုင်ငံအတွက် နေ့စဉ် ကြော်ငြာတင်သူ အရေအတွက်အတိအကျနှင့် ပြိုင်ဘက် Targeting ကို ထုတ်ပြန်မထားပါ။ Live link များသည် Meta Ad Library မှ တကယ့် Live ဒေတာကို တိုက်ရိုက်ဖွင့်ပေးခြင်း ဖြစ်သည် — ကိန်းဂဏန်းအတု မပြပါ။
- Reach / Budget ခန့်မှန်းချက်များသည် အကြမ်းဖျင်း ခန့်မှန်းချက်များသာ ဖြစ်ပြီး အာမခံချက် မဟုတ်ပါ။
